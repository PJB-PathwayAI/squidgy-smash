# Squidgy Smash

A playable retro arcade prototype built for the PathwayAI Ltd Web Summit Qatar 2027
partnership campaign.

Single self-contained HTML file. No dependencies, no build step, no backend.

## Play

Open `index.html`, or visit the GitHub Pages link for this repository.

## What this is

A demonstration artefact. It shows the game, the sponsor inventory (two banner
slots plus in-game partner plates), and the between-level partner cards.

The sponsor names in the game are fictional placeholders. No real partner branding
appears anywhere.

## What this is not

Not a product. There is no backend, no shared leaderboard and no impression
logging. Scores are stored on the player's own device.

## Status

Prototype. Gameplay is frozen and approved. Sponsor branding is not to be sold
until the Lite version has been tested on real hardware.
